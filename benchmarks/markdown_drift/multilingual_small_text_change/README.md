# Multilingual small text (non-claims)

このフィクスチャは、**言語だけを変える**（本文の記述のみを差し替える）という小さな変化を対象にする。

## 非主張（Non-claims）

- これは **言語間一般化**や、任意言語への外挿を主張しない。
- 構造差分エンジンが検出するのは、抽出対象（見出し/リンク/数値/引用など）に限られる。
- 本ケースではそれらの抽出要素が不変であることを狙い、**fixture-local** のルールベース検知の頑健性を確認する。

## 期待

- 構造抽出要素が変わらないため、`classification` は `preserved`。
- `required_action` は `approve`。
