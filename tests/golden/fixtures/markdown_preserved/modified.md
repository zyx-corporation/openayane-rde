# OpenAyane Introduction

OpenAyane is an agent safety framework based on resonant deviation evaluation.

## Core Principles

**RDE**: A resonant deviation evaluator that classifies semantic changes.

The threshold for critical deviation is 0.85.

See [Smith 2020](https://example.com/smith2020) for background theory.

## Summary

The framework ensures that unauthorized changes to protected elements are detected
before they are applied.
